# Version 2.2.0 Update 🚀


### 🆕 New Feature
* **First-Time Setup:** On the first start, the app now shows a welcome screen where you can create your database with a single tap.

* **Error Logging:** The app now keeps a log file in `Documents/AttendlyDb/logs` to make problems easier to trace. The recent log entries can be viewed and copied in the Debug menu. The log file limits its own size, so no cleanup is needed.


### 🐛 Bug Fixes
* **Fresh Installation:** Fixed the "Critical Settings Error" screen after installing the app for the first time, and the "Database open/switch failed" screen after restarting it.

* **Database Errors:** If a database cannot be opened (also when switching to an older one), you can now retry, create a new database (with a warning first) or go back to the default database.

* **Settings:** Changing the theme or language no longer resets the active database to the previous year after a year change.



### 🔮 Looking Ahead: Version 3.0.0

* While Version 2.0.0 focuses on the invisible engine powering the app, our next major release is already in the works! Version 3.0.0 will bring a comprehensive update to the User Interface (UI), making the app even more intuitive, visually appealing, and easier to navigate.
